# Colab notebooks

`sitesight_m5_colab_v2.ipynb` is the M5 fine-tuning notebook as it was run on a Colab T4, with its saved
cell outputs. It is committed unedited, so the printed test table can be compared with
`reports/m5/test_final.json` (mAP@0.5 34.0, recall@0.5 46.5, ECE 0.459 for the LoRA model).

The intro cell was written for the validation run and still says the test split is not used. The
final test evaluation (cell 1, `--allow-test`) was run once from this same notebook; the table in
its output is that run.

The M4, M6 and M7 notebooks are generated by `scripts/build_colab_notebook.py` and are not committed.

`sitesight_m9_colab_v1.ipynb` is the RGB-D odometry run on TUM fr1/desk, with its saved outputs; its
numbers are the ones in `reports/m9/metrics.json`.
